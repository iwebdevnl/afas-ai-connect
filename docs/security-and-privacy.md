# Security and privacy

AFAS AI Connect is built and hosted by iWebDevelopment, which is ISO 27001
certified. Core infrastructure runs in the EU.

- Every write action is prepared as a draft you approve before anything is posted.
- The connection runs within the scope of the AFAS AppConnector configured in your environment.
- The authoritative terms are in iWeb's
  [Algemene Voorwaarden (AV)](https://www.iwebdevelopment.com/hubfs/144641067/Files/algemene-voorwaarden.pdf) and the DPA.

Full documents on GitHub:

- Trust and the write-approval model: https://github.com/iwebdevnl/afas-ai-connect/blob/main/TRUST.md
- Privacy and data handling: https://github.com/iwebdevnl/afas-ai-connect/blob/main/PRIVACY.md
- Security reporting: https://github.com/iwebdevnl/afas-ai-connect/blob/main/SECURITY.md
